# شطورة يا جنى

صفحة احتفال تفتح على «شطورة يا جنى». اسم جنى يظهر حروف عربي بتتنطط، وتحته Jana بالإنجليزي، مع سماء ليلية وبالونات وألعاب نارية.

## تشغيلها عندك

```bash
npm install
npm run dev
```

الموقع يشتغل على [http://127.0.0.1:43123](http://127.0.0.1:43123).

- دوس في السما عشان لعبة نارية تفرقع في المكان ده.
- دوس على بالون عشان يتفرقع.
- دوس على حرف عشان يطلع بلونه.
- «فرّعي السما» تطلع دفعة ألعاب نارية.
- «شغّلي الأغنية» تشغّل لحن خفيف، وتقدر تهديه تاني.

## GitHub Pages

الصفحة المنشورة: https://omarapdelgwad44.github.io/shatora-ya-jana/

الملفات متجهزة للنشر من GitHub Actions. بعد ما المستودع يبقى على جيت هب:

1. من Settings ثم Pages، خلّي Source على **GitHub Actions**.
2. ادفع على فرع `main`.
3. أكشن **Deploy to GitHub Pages** هيبني الموقع وينشره.

العنوان هيبقى بالشكل ده: `https://USERNAME.github.io/REPO/`
